# Realset headline (read first)

**Scope.** Emberz targets *live manipulation*: a person who builds trust over several turns, then asks for a code, money or secrecy (bank/government impersonation, family emergency, grooming). Its main benchmark is the held-out set of two-sided manipulation calls (results/guardian_snapshot.json). This real-audio set is a **supporting check** of two things: (1) the real phone path (8 kHz audio, live Nemotron ASR) and (2) false alarms on real, unscripted benign calls. The scam side is one-sided recorded robocalls ("press 1", "call us back"). Robocall screening is **out of scope**: carriers already block or label robocalls before the phone rings (STIR/SHAKEN), and a recorded pitch has no conversation for the guardian to read. We still report it, because it shows where the model stops.

- **Deployment drift check (Matt, 16:00):** the dedicated deployment may serve the fine-tune only partially, so we re-scored all 1,233 turns through the sampler proxy that serves the exact evaluated checkpoint (tag emberz-guardian-v2-proxy). Test split: 45/90 scams (40-60%), 17/60 false alarms (19-41%); all 301: 93/181, 33/120. Same picture, so drift does not explain the robocall gap.
- **Test set:** 301 real phone calls (181 NCSU scam robocalls, 120 HarperValley bank calls), run through our 8 kHz phone path and live ASR. A seeded held-out test split has 150 calls (90 scam, 60 benign). Every chat model got the same transcripts and the same frozen prompt. Rune got the same prompt through the decisions API as two multiple-choice questions, so it is close to like-for-like but not identical.
- **Frontier baselines on test:** Kimi K3 (named baseline) caught 88/90 scams = 98% (95% CI 92-99%) with 17/60 false alarms = 28% (19-41%). Qwen3.8 Max caught 85/90 = 94% (88-98%) with 17/60 = 28% (19-41%). Kimi and Qwen are statistically tied.
- **Matt's fine-tuned guardian (Emberz v2) on test:** caught 47/90 = 52% (42-62%) with 15/60 false alarms = 25% (16-37%). AUC 0.64 vs 0.85 for Kimi K3.
- **Bottom line: our fine-tune does not beat the named baseline on this set.** Scam recall is far worse. False alarms are a statistical tie.
- **Where it loses:** scam recall. It is 46 points below Kimi K3 on test (95% CI -56 to -36, McNemar p<0.001), and -47 points over all 301 calls. Kimi caught 85 scams that ours missed; ours caught none that Kimi missed. Ours misses 19/19 auto-warranty, 10/11 prize and 32/42 tech-support/utility robocalls. On those it rates the "press one / call us back" pitch only `watch`.
- **The gap holds when duplicate campaigns are collapsed.** Many robocalls are the same script recorded more than once: by 4-gram overlap, the 181 scams form about 84 campaign clusters (107 at a stricter cut). Weighting each campaign once, ours catches 53% vs Kimi's 95%, a difference of -42 points (cluster bootstrap 95% CI -52 to -32). The headline CIs treat every call as independent, so they are too narrow. With clustering, our all-call recall CI is about 37-64%, not 43-57%.
- **Where it is ahead of Kimi K3, with caveats:** latency and cost, but only against the two frontier models. Its p50 latency is 860 ms vs 2,324 ms for Kimi K3 and 3,024 ms for Qwen3.8 Max. That compares a dedicated GPU with shared serverless endpoints, so it is not a like-for-like speed test. Cost is about $8.42 vs $10.93 per 1,000 calls. Ours is summed request time at $8/h with idle time left out, so a real deployment that sits idle would cost more. False alarms come out 3 points lower than Kimi on test (-12 to +7, p=0.73). That is a tie, not a win. One slice favours ours: order-checks bank calls, where the agent asks for an address (6/15 flagged vs Kimi's 13/15, all calls). We picked that slice after seeing the results, and on pay_bill ours is worse (10/15 vs 8/15), so it is a lead, not a finding.
- **Cheaper baseline worth noting:** Nemotron Lightning 3.5 caught 84/90 = 93% on test with 15/60 = 25% false alarms, at $0.19 per 1,000 calls and 449 ms p50. That is close to Kimi K3. It also beats our guardian on recall, latency and cost at once.
- **Caveats:** the robocalls are one-sided, and the benign calls put the bank agent on the caller side. Scams and benign come from different sources, so speaking style can give away the label. Duplicate campaigns span both splits (23 clusters have calls in dev and in test), so dev and test are not fully independent. Only the threshold choice used dev. Labels are per source: a few NCSU calls are telemarketing rather than fraud (solar, TV discounts), and a few transcripts are only an IVR tail ("press two to listen again"). The guardian was trained on two-sided conversations, so these robocalls are out of distribution for it. That is a limit of the fine-tune, not an excuse for it.
