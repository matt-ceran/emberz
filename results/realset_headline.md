# Realset headline (read first)

- **Test set:** 301 real phone calls (181 NCSU scam robocalls, 120 HarperValley bank calls), run through our 8 kHz phone path and live ASR. A seeded held-out test split has 150 calls (90 scam, 60 benign). Every model got the same transcripts and the same frozen prompt.
- **Frontier baselines on test:** Kimi K3 (named baseline) caught 88/90 scams = 98% (95% CI 92-99%) with 17/60 false alarms = 28% (19-41%). Qwen3.8 Max caught 85/90 = 94% (88-98%) with 17/60 = 28% (19-41%). Kimi and Qwen are statistically tied.
- **Matt's fine-tuned guardian (Emberz v2) on test:** caught 47/90 = 52% (42-62%) with 15/60 false alarms = 25% (16-37%). AUC 0.64 vs 0.85 for Kimi K3.
- **Where it loses:** scam recall. It is 46 points below Kimi K3 on test (95% CI -56 to -36, McNemar p<0.001), and -47 points over all 301 calls. Kimi caught 85 scams that ours missed; ours caught none that Kimi missed. Ours misses 19/19 auto-warranty, 10/11 prize and 32/42 tech-support/utility robocalls, because it rates "press one / call us back" pitches only `watch`.
- **Where it wins:** speed. Its p50 latency is 860 ms vs 2,324 ms for Kimi K3 and 3,024 ms for Qwen3.8 Max. Cost is a little lower: about $8.42 vs $10.93 per 1,000 calls (ours is a rough GPU-time figure). False alarms come out 3 points lower than Kimi on test (-12 to +7, p=0.73), which is a tie, not a win. Its clearest edge is bank calls where the agent asks for an address: 6/15 order-checks calls flagged vs Kimi's 13/15.
- **Cheaper baseline worth noting:** Nemotron Lightning 3.5 caught 84/90 = 93% on test with 15/60 = 25% false alarms. That is close to Kimi K3 at $0.19 per 1,000 calls and 449 ms p50.
- **Caveats:** the robocalls are one-sided, and the benign calls put the bank agent on the caller side. Scams and benign come from different sources, so speaking style can give away the label. The guardian was trained on two-sided conversations, so these robocalls are out of distribution for it. Full write-up: [realset.md](realset.md).
