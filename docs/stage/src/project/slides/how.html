How it works

Every caller turn, scored live.

Caller

Any number, any voice, human or AI

→

Guarded line

Telnyx Call Control: notice, conference, both audio tracks

→

Live speech-to-text

NVIDIA Nemotron Speech Streaming 0.6B, INT8, 160 ms chunks

→

Guardian

Qwen3.6-35B-A3B LoRA, fine-tuned and served on Fireworks

→

Action

Coach whisper, caretaker call, console alert

The guardian reads the caretaker’s rules and the last 8 turns, and returns risk, category, an evidence quote, a coach line and a caretaker note as JSON.

One frozen prompt for training, evaluation and the live line. If the endpoint is down, Nemotron Lightning 3.5 on Fireworks serverless takes over.

Under the hood: the call lands on our Telnyx line, both sides are transcribed live by NVIDIA Nemotron Speech Streaming running locally, and after every caller turn our fine-tuned guardian on Fireworks reads the conversation and the family’s rules and returns a structured verdict. The same prompt is used in training, in the benchmark and on the live line, so what we measured is what runs. And a call is never left unguarded: if the guardian endpoint is down, it falls back to Nemotron Lightning on Fireworks serverless.
